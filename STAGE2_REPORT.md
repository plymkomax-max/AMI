## Ключевые принципы, соблюдённые в реализации

1. **Не удаляем данные** — архивация вместо удаления (история рынка важна).
2. **Дедупликация** — стабильный ID из `(source, external_id)`, повторный ввод = обновление.
3. **История цен** — `PriceHistory` + `ListingHistory` пишутся при каждом изменении.
4. **Гибкий маппинг колонок CSV** — поддержка русских и английских заголовков.
5. **Нормализация** — цены (пробелы, запятые, валюты) и состояние (синонимы).
6. **CPU-friendly** — всё на CPU, без CUDA, без тяжёлых библиотек.
7. **Безопасность** — валидация входных данных, обработка ошибок, логирование.
